# Flutter Notification System - Examples

Este directorio contiene ejemplos de cómo usar el Flutter Notification System en tu aplicación.

## Ejecutar el ejemplo

```bash
cd example
flutter pub get
flutter run
```

## Ejemplos incluidos

1. **Basic Example** - Ejemplo básico de notificaciones
2. **Advanced Features** - Características avanzadas como prioridades, colas y temas personalizados
3. **Operation Result Tracking** - Seguimiento de operaciones CRUD con mixins
